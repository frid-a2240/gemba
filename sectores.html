Manufactura

Dispositivos médicos

Un sector regulado en el que la trazabilidad y la gestión del riesgo protegen la salud del paciente.

  • ISO 13485
  • ISO 14971

Cómo le apoyamos

  • Implementación del sistema de gestión ISO 13485
  • Gestión de riesgos a lo largo del ciclo de vida del producto
  • Validación de procesos y control de cambios
  • Trazabilidad, control de documentos y registros
Manufactura

Aeroespacial

Seguridad, confiabilidad y control riguroso de la configuración en cada etapa de la cadena de suministro.

  • AS9100
  • AS9102

Cómo le apoyamos

  • Implementación y certificación AS9100
  • Inspección de primer artículo (FAI)
  • Gestión de configuración y riesgos operacionales
  • Prevención de partes falsificadas y de daño por objetos extraños (FOD)
Manufactura

Electrónica

Altos volúmenes, componentes sensibles y criterios de aceptación estrictos en cada etapa del ensamble.

  • ISO 9001
  • IPC-A-610
  • Control de ESD

Cómo le apoyamos

  • Sistema de gestión de calidad para manufactura electrónica
  • Criterios de aceptabilidad de ensambles
  • Programa de control de descargas electrostáticas
  • Reducción de defectos mediante herramientas estadísticas
Manufactura

Automotriz

Una cadena de suministro con altas exigencias de calidad y requisitos específicos para cada cliente.

  • IATF 16949
  • Core Tools AIAG
  • CSR

Cómo le apoyamos

  • Implementación y certificación IATF 16949
  • APQP, PPAP, AMEF, SPC y MSA aplicados a sus lanzamientos
  • Cumplimiento de requisitos específicos del cliente
  • Auditorías de proceso y producto a proveedores
Manufactura

Contract Manufacturing

Organizaciones que manufacturan para diversos clientes y deben cumplir, al mismo tiempo, con requisitos y normas de distintas industrias.

  • ISO 9001
  • Sistemas integrados

Cómo le apoyamos

  • Sistemas de gestión que atienden requisitos de múltiples clientes
  • Gestión de requisitos específicos por cliente y por producto
  • Transferencia y lanzamiento de nuevos productos
  • Preparación para auditorías de clientes
Manufactura

Metal-mecánico

Procesos cuya calidad no siempre es visible a simple vista y que requieren un control riguroso de sus parámetros.

  • ISO 9001
  • CQI-9
  • CQI-11
  • CQI-12
  • CQI-15

Cómo le apoyamos

  • Evaluación de procesos especiales: tratamiento térmico, recubrimientos y soldadura
  • Control de procesos de maquinado, estampado y fundición
  • Planes de control y estudios de capacidad
  • Lean Manufacturing para reducir tiempos y desperdicios
